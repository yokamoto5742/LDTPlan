# 変更履歴

このファイルは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) の形式に従い、バージョン番号は [セマンティック バージョニング](https://semver.org/lang/ja/) に準拠する。

## [1.1.1] - 2026-10-12

### 修正

- 出力した計画書でボタンの表示文字が「ボタン 3」などの既定名になる不具合を修正（ClosedXMLが保存時に破棄するフォームコントロールのVML描画を、保存後にテンプレートから復元する）

## [1.1.0] - 2026-10-12

### 追加

- 新規作成・編集画面に作成回数の入力欄を追加（新規作成時の初期値は1）
- 計画書一覧に回数列を追加
- 前回計画コピー時に作成回数を1つ増やす処理を追加
- CSV出力/取込に `creation_count` 列を追加

### 変更

- 共通情報シートのB13セルに作成回数を出力するよう変更
- 初回用/継続用シートの切替を、同一患者の先行レコードの有無ではなく作成回数が1かどうかで判定するよう変更
- `patient_info` テーブルに `creation_count` 列を追加（列のない既存の `ldtp_app.db` は再作成が必要）
