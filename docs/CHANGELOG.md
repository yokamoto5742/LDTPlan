# 変更履歴

このファイルは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) の形式に従い、バージョン番号は [セマンティック バージョニング](https://semver.org/lang/ja/) に準拠する。

## [1.1.41] - 2026-10-30

### 変更

- 「保存して印刷」でも「保存」と同じく必須項目を確認し、ホーム画面で表示中の患者の基本情報を記録に反映するようにした

## [1.1.40] - 2026-10-30

### 変更

- 編集画面の「印刷」ボタンを「保存して印刷」に名前を変え、左端に移した。ボタンの並びは「保存して印刷」「保存」「削除」「戻る」になる
- 「保存して印刷」で計画書を作成したあとは、「新規登録して印刷」と同じようにホーム画面に戻るようにした。作成に失敗したときは編集画面に残る

## [1.1.39] - 2026-10-28

### 修正

- OKボタンのない通知で、ボタンがあった場所の余白が下に残っていた問題を修正し、文字に合わせた大きさで表示するようにした
- 通知を自動で閉じるまでの時間を1秒にした

## [1.1.38] - 2026-10-28

### 変更

- 「保存しました」「テンプレートを保存しました」の通知からOKボタンをなくし、2秒後に自動で閉じるようにした。エラーや削除の確認は従来どおりボタンで操作する

## [1.1.37] - 2026-10-28

### 追加

- ホーム画面を閉じた位置を端末ごとに記憶し、次回はその位置から開始するようにした。位置はユーザーのローカルフォルダ内の LDTPlan\window_position.txt に保存する。保存がない場合や、モニターの変更で画面外になった場合は、これまでどおり画面中央に表示する

## [1.1.36] - 2026-10-27

### 修正

- 電子カルテから起動したとき、特に初回起動で、ホーム画面が他のアプリの後ろに表示されることがある問題を修正した。起動時は他のアプリの表示に関わらず最前面に出し、患者ID欄に入力できる状態にする。最前面になるのは起動時だけで、その後に開く Excel などは通常どおり手前に表示される
- 二重起動したときも、起動済みの画面を同じ方法で最前面に出すようにした
- 起動中の表示を常に手前に表示し、起動を待つ間に他のアプリを操作しても隠れないようにした
- 前面に出せたかどうかを startup.log に記録する。前面に出せなかったときはタスクバーのボタンを点滅させる

## [1.1.35] - 2026-10-26

### 修正

- Windows の「テキストのサイズ」を100%より大きくした端末で、文字だけが拡大されて画面の右側や下側が切れる問題を修正した。設定の倍率を打ち消し、どの端末でも config.ini の font_size どおりの大きさで表示する
- 配布する config.ini の画面幅を1150に変えたのに合わせ、設定の読込テストの期待値を直した

## [1.1.34] - 2026-10-25

### 変更

- メイン画面の下部に表示していたステータスバーを削除した。コピー完了とウィンドウ幅不足の通知はなくした
- 操作マニュアルを開けないときは、ステータスバーではなく警告ダイアログで知らせる

## [1.1.33] - 2026-10-24

### 追加

- 列を追加したときの更新漏れを検出するテストを追加した。テストデータ・編集画面の読込と保存・テンプレートの適用と保存・共通情報シートへの書き込みが対象
- 配布先の Excel テンプレートから計画書ファイルを生成し、VBA マクロ・バーコード画像・ボタンの描画・開くシートを確かめるテストを追加した。テンプレートがない環境ではスキップする
- 静的解析を有効にし、警告をエラーとして扱うようにした。設定は Directory.Build.props と .editorconfig に置き、dotnet format で書式を確かめられる
- 画面の変更を手動で確かめるためのチェックリストを docs/manual-test-checklist.md に追加した

### 変更

- テンプレートの取得と保存を編集画面から PatientService に移した。保存は全列をまとめて上書きするため、列を追加しても上書き漏れが起きない
- db_url の接頭辞の判定をカルチャに依存しない比較にした
