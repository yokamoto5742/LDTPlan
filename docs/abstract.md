# 日本メディカルAI学会学術集会 一般演題 抄録案

## 演題名

- 医療秘書がAIコーディングで開発した生活習慣病療養計画書アプリの2年間の運用実績

## 構成の意図

| 聴衆（主に医師）の問い | 抄録で答える箇所 |
|---|---|
| 自院でも作れるのか？ | 【方法】開発経験のない医療秘書がAIで開発 |
| 臨床の時間は戻るのか？ | 【結果】延べ33,498件・継続作成率・変更項目数・作成時間 |
| 作った後に責任を持てるのか？ | 【結果】改修2～3日・1週間での再構築／【考察】設計と運用があれば作り直せる |
| 何が成功の条件か？ | 【考察】要件の言語化・実使用での評価・院内連携 |

結論は「AIがあれば誰でも作れる」ではなく、「**現場の運用を言葉にでき、実際に使って評価できる人がいれば作れる**」とする。

## 抄録本文

【背景】2024年度診療報酬改定で生活習慣病管理料（Ⅱ）の算定に生活習慣病療養計画書の発行が必要となった。公開されているExcel様式では患者データが残らないので作成負担が大きかった。

【目的】医療秘書がAIコーディングで生活習慣病療養計画書アプリを開発し、その有用性を検討する。

【方法】内科医師の要望を基に医療秘書がアプリの画面と要件を言語化し、Anthropic社のClaudeを用いてPythonのFletでアプリを構築した。計画内容を患者ごとにデータベースへ保存し、継続作成時は前回内容を複製して差分のみを修正する方式とした。作成時間を短縮するため、主病名が高血圧、糖尿病、脂質異常症に対しそれぞれ病状に応じた3種類のテンプレートを用意した。電子カルテからの患者情報取得は情報システム部門の確認を経て導入した。本格運用開始後2年間で医師が作成した延べ33,498件で計画書の継続作成率と前回からの変更項目数を集計した。無作為に抽出した10件で作成時間を計測した。

【結果】アプリは2024年6月から試験導入し、同年9月より本格運用を開始した。患者5,134名、医師30名が利用し、作成数は月約1,400件で24か月安定した。適用した疾患別テンプレートの割合は高血圧症56.3%、糖尿病30.0%、脂質異常症13.7%であった。アプリに保存した前回計画内容からの継続作成件数は28,602件（85.4%）で、計画更新間隔は中央値91日、88.6%が120日以内だった。1回の作成で前回から変更した項目は平均0.5項目で、74.6%は変更がなかった。一方で患者単位では、60.4%が2年間のうちに指導内容を1回以上変更していた。作成時間は手入力の約3分から約20秒に短縮し、2年間で約1,490時間の削減と推計した。医師からのアプリ改善要望は2～3日で反映した。2026年10月にアプリの起動遅延とFlet更新への追従困難に対し、Anthropic社のClaude Codeを用いて実作業日数12日でC#の.NETで再構築した。

【考察】前回複製方式で医師は不変の項目の再入力を省き、必要時に修正した。AIコーディングには運用に即した要件の言語化、医師の実使用による評価とフィードバック、情報システム部門との連携が重要であった。アプリの設計が明確であったため、短期間で別言語に再構築できた。

【結論】医療秘書がAIコーディングにより診療報酬改定に対応するアプリを開発・運用・再構築し、内科外来診療と医師の文書作成業務の効率化に寄与した。
