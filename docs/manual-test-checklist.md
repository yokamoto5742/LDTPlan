# 手動テストのチェックリスト

画面（`Forms/`）は自動テストがないため、画面を変更したときやリリース前に確認する。
項目とレコードの対応・テンプレートの保存・計画書ファイルの生成は自動テストで確認しているので、ここでは画面の動きだけを見る。

## ホーム画面

- [ ] 起動時に pat.csv の患者が読み込まれ、患者情報と計画書一覧が表示される
- [ ] 患者IDを入力すると、その患者の計画書一覧に切り替わる
- [ ] 一覧の行をクリックすると編集画面が開く
- [ ] 前回計画コピーで、最新の計画書が今日の発行日・作成回数+1で一覧に追加される
- [ ] pat.csv を削除するとアプリが終了する

## 新規作成画面

- [ ] 作成回数が1、発行日が今日で開く
- [ ] 主病名を選ぶと、シート名がその主病名のものに絞り込まれる
- [ ] シート名を選ぶと、テンプレートの内容が各項目に入る
- [ ] 非喫煙者と禁煙の指導は、片方をチェックするともう片方が外れる
- [ ] 食事・運動のドロップダウンを選ぶと、次の項目にフォーカスが移る
- [ ] 主病名・シート名が未選択のまま保存するとエラーが表示される
- [ ] 作成回数・目標体重に数字以外を入れて保存するとエラーが表示される
- [ ] 新規登録して印刷で、Excel が開き、バーコードとボタンが表示される

## 編集画面

- [ ] 保存した内容がすべて表示される
- [ ] 保存・印刷・削除が動き、削除前に確認が表示される

## テンプレート編集画面

- [ ] 作成回数・発行日と、眼科・歯科・がん検診が表示されない
- [ ] 保存したテンプレートが、新規作成でシート名を選んだときに反映される

## 表示

- [ ] config.ini の font_size・画面の大きさを変えたとき、文字や入力欄が切れない
